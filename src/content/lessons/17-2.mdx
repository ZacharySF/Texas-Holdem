<Idea>

A seed initializes the pseudo-random generator’s internal state. The same inputs and seed produce the same sampled sequence. That is valuable for replaying a result and comparing code changes. It is not a secret source of true uncertainty, and it does not make a flawed model fair.

An error bar on a Monte Carlo mean describes sampling variation conditional on all supplied assumptions. It omits errors in ranges, future actions, rake, and the game model. Exact enumeration removes numerical sampling error but preserves those assumptions. A deterministic exact answer can therefore still be an inappropriate input to a real decision.

Progress charts display many pointwise intervals. They are not one simultaneous band guaranteed to contain the truth at every displayed time. Optional stopping after a favorable estimate can distort inference. Compare fixed sample sizes with controlled distributions and independent seeds when assessing accuracy; use the saved seed when reproducing a particular calculation.
